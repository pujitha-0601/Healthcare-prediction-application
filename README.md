# 🏥 Healthcare Prediction Application

A simple and secure Streamlit application to predict health risks based on patient blood test values.

### ✨ Features
- **Unique Email Validation:** Prevents duplicate entries. Shows error if email already exists.
- **Smart Validation:** Validates Name, Email format, DOB, and Blood values.
- **Health Prediction:** Rule-based prediction for Diabetes, Anemia, and Cholesterol risks.
- **CRUD Operations:** Add, View, Edit, Delete patient records.
- **Local Database:** All data stored securely in SQLite (`patient_records.db`).

### 🛠️ Tech Stack
- **Frontend:** Streamlit
- **Backend:** Python
- **Database:** SQLite3
- **Logic:** Rule-based medical rules
